Web, Desktop (Electron / .NET) & Mobil (Flutter / React Native) Softphone SDK Rehberi

Nornia santralinin arama, cevaplama, aktarma, bekletme ve gelen çağrı yakalama (CRM Screen Pop) yeteneklerini kendi Web CRM, Electron Desktop, C#/.NET veya Flutter / React Native mobil uygulamanızın içine 5 dakikada kopyala-yapıştırla gömmek için sıfırdan adım adım geliştirici kılavuzu.

Santral Menü Yolu & URL
Teknik Dokümantasyon → Desktop & Mobil Softphone SDK
/api/v1/sdk/session
Gerekli Rol Yetki Kodları (RBAC)
Yazılım Geliştirici • External API Anahtarı (sdk:webrtc veya calls:write)
Başlamadan Önce Ön Koşullar
  • Nornia yönetim panelinden `Yönetim → API Yönetimi` menüsüne girip yeni bir API Anahtarı (`aida_live_...`) oluşturun ve **`sdk:webrtc`** (veya `calls:write`) yetkisini işaretleyin.
  • Bağlanacağınız dahili numaranın (ör. `1001`) `Santral → Kullanıcılar` altında aktif olduğunu doğrulayın.
  • WebRTC mikrofon erişimi için sayfanızın **`https://`** (veya geliştirme ortamında `http://localhost`) üzerinden açılması ve santralin **8089/TCP (WSS)** portunun açık olması gerekir.
  • Bu SDK'yı kullanmak için hiçbir SIP/VoIP protokolü bilmenize gerek yoktur; Nornia tüm SIP, WSS, STUN/TURN ve NAT ayarlarını tek bir API çağrısıyla otomatik verir.

2. Adım 0 — API Anahtarı Alma (1 Dakika)

Kodu çalıştırmadan önce santralinizden bir API anahtarı almanız gerekir. Bu işlem sadece 1 kez yapılır:

  1. 1Nornia yönetici paneline giriş yapın ve sol menüden `Yönetim → API Yönetimi` ekranını açın.
  2. 2Sağ üstteki `+` butonuna tıklayıp yeni anahtar oluşturun (Ad: örn. `CRM Softphone SDK`).
  3. 3Yetki listesinden **`Desktop, Web & Mobil Softphone SDK → sdk:webrtc`** kutucuğunu işaretleyin (Click-to-Call de kullanacaksanız `calls:write` yetkisini ekleyin).
  4. 4Ekranda bir kez gösterilen `aida_live_...` anahtarını kopyalayıp güvenli bir yere kaydedin. Güvenlik için bu anahtarı üretimde kendi backend'inizde tutmanız veya yalnızca yetkili kurum içi CRM'de kullanmanız önerilir.

3. En Kolay Yol: 3 Satırda Hazır Mini Telefon Widget'ı (Kopyala-Yapıştır Test)

Hiç arayüz kodu yazmak istemiyorsanız, bilgisayarınızda `test.html` adında boş bir dosya açıp aşağıdaki kodu olduğu gibi yapıştırın. Sadece 3 alanı (`serverUrl`, `apiKey`, `extension`) kendinize göre değiştirip tarayıcıda açın — sağ alt köşede tam çalışan Nornia telefonu anında açılacaktır!

<!DOCTYPE html>
<html lang="tr">

  <title>Nornia SDK Test</title>
</head>
<body>
  <h2>Müşteri CRM Ekranım</h2>
  <p id="arayanBilgi">Henüz gelen çağrı yok...</p>

  <!-- 1. Adım: İki SDK dosyasını doğrudan kendi Nornia sunucunuzdan yükleyin -->
  <script src="https://SANTRAL-ADRESINIZ/api/v1/sdk/nornia-voice-sdk.js"></script>
  <script src="https://SANTRAL-ADRESINIZ/api/v1/sdk/nornia-softphone-widget.js"></script>

  <!-- 2. Adım: Telefonu ekrana bağlayın -->
  <script>
    const widget = NorniaSoftphoneWidget.mount({
      serverUrl: "https://SANTRAL-ADRESINIZ",   // Örn: https://pbx.firma.com
      apiKey: "aida_live_BURAYA_ANAHTARINIZ",   // API Yönetimi'nden aldığınız anahtar

      themeColor: "#4f46e5",                    // Kendi kurumsal renginiz

5. Masaüstü Uygulamaları: Electron Desktop & C# / .NET / Python (Click-to-Call)

Electron tabanlı masaüstü uygulamalarınızda yukarıdaki `nornia-voice-sdk.js` birebir çalışır; yalnızca `main.js` içinde mikrofon iznine onay vermeniz yeterlidir. C# / .NET (WinForms/WPF), Delphi veya Python masaüstü programlarınızda ise hiç WebRTC yazmadan tek bir HTTP POST isteğiyle kullanıcının masa telefonundan veya Runa uygulamasından **Click-to-Call** başlatabilirsiniz.

A) Electron main.js (Mikrofon İzni) & B) C# .NET Click-to-Call Örneği
// --- A) ELECTRON DESKTOP (main.js) — Mikrofon İznini Otomatik Onayla ---
const { session } = require("electron");
app.whenReady().then(() => {
  session.defaultSession.setPermissionRequestHandler((webContents, permission, callback) => {
    if (permission === "media") return callback(true);
    callback(false);
  });
});

// --- B) C# / .NET (WinForms / WPF / ERP) — Tek İstekle Click-to-Call ---
using var http = new HttpClient();
http.DefaultRequestHeaders.Add("X-API-Key", "aida_live_BURAYA_ANAHTARINIZ");
var body = new StringContent(
    "{"extension":"1001","destination":"05321234567"}",
    System.Text.Encoding.UTF8,
    "application/json"
);
var resp = await http.PostAsync("https://pbx.firma.com/api/v1/calls/originate", body);
Console.WriteLine(await resp.Content.ReadAsStringAsync());

6. Mobil Uygulamalar: Flutter (iOS & Android) ve React Native

Kendi kurumsal mobil uygulamanıza (saha ekibi veya uygulama içi müşteri desteği) sesli arama eklemek için santralinizden hazır mobil SDK dosyasını indirip projenize koymanız yeterlidir.

  1. 1Flutter için `https://pbx.firma.com/api/v1/sdk/nornia-mobile-sdk.dart` dosyasını indirip projenizdeki `lib/nornia_mobile_sdk.dart` yoluna kaydedin.
  2. 2`pubspec.yaml` dosyanıza `http: ^1.2.0` ve `sip_ua: ^1.0.0` paketlerini ekleyip `flutter pub get` çalıştırın.
  3. 3Android için `AndroidManifest.xml` içine `RECORD_AUDIO`, `INTERNET`, `MODIFY_AUDIO_SETTINGS` izinlerini; iOS için `Info.plist` içine `NSMicrophoneUsageDescription` açıklamasını ekleyin.
  4. 4React Native kullanıyorsanız `https://pbx.firma.com/api/v1/sdk/nornia-mobile-sdk.js` dosyasını projenize kopyalayıp `npm install sip.js@0.20.1 react-native-webrtc` kurun.
Flutter (Dart) & React Native — 10 Satırda Çalışan Mobil Arama Örneği
// ===================== FLUTTER (lib/main.dart) =====================
import 'nornia_mobile_sdk.dart';

final nornia = NorniaMobileSDK(
  serverUrl: 'https://pbx.firma.com',
  apiKey: 'aida_live_BURAYA_ANAHTARINIZ',
  extension: '1001',
  onRegistrationChanged: (ok) => print('Santral Bağlı: $ok'),
  onIncomingCall: (call, caller) => print('Gelen Arama: $caller'),
);

// Bağlan ve Ara:
await nornia.connect();
await nornia.dial('05321234567');
// Gelen aramayı açmak için: nornia.answer();  Kapatmak için: nornia.hangup();

// ================== REACT NATIVE (App.js) ==================
import { NorniaReactNativeSDK } from "./nornia-mobile-sdk";

const phone = new NorniaReactNativeSDK({
  serverUrl: "https://pbx.firma.com",
  apiKey: "aida_live_BURAYA_ANAHTARINIZ",
  extension: "1001",
  onRegistered: (ok) => console.log("Bağlı:", ok),
  onIncomingCall: ({ callerNumber }) => console.log("Arayan:", callerNumber),
});

await phone.connect();
await phone.dial("05321234567");

7. SDK Oturum API Referansı (`POST /api/v1/sdk/session`)

Kendi özel dilinizde (Swift, Kotlin, C++, Go vb.) entegrasyon yapıyorsanız doğrudan bu REST ucunu çağırarak tüm WebRTC/SIP parametrelerini alabilirsiniz.

Güvenlik En İyi Uygulaması (Üretim Ortamı İçin)
Tarayıcıda çalışan genel bir web uygulamasında `X-API-Key` anahtarını istemci koduna açık yazmak yerine, kendi backend sunucunuzun `/api/v1/sdk/session` isteğini yapıp dönen JSON'ı yalnızca oturum açmış kendi kullanıcınıza vermesi en güvenli yaklaşımdır.

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: HTTP 401 veya 403 Yetki Hatası dönüyor
Kök Neden: `X-API-Key` başlığı eksik/hatalı veya anahtarda `sdk:webrtc` / `calls:write` yetkisi işaretlenmemiştir.
Çözüm: `Yönetim → API Yönetimi` ekranında anahtarın aktif olduğunu ve `sdk:webrtc` iznine sahip olduğunu kontrol edin.
Belirti: Tarayıcıda mikrofon izni sormuyor veya ses gitmiyor
Kök Neden: Tarayıcılar güvenlik gereği yalnızca `https://` veya `http://localhost` adreslerinde WebRTC mikrofon erişimine izin verir.
Çözüm: Sayfanızı `http://192.168.x.x` yerine `https://` üzerinden veya geliştirme sırasında `http://localhost` üzerinden açın.
Belirti: WSS bağlantısı (`wss://...:8089/ws`) kurulamıyor
Kök Neden: Güvenlik duvarında 8089/TCP portu kapalıdır veya santralin SSL sertifikası self-signed olduğu için tarayıcı reddediyordur.
Çözüm: 8089/TCP portunu açın ve geçerli bir Let's Encrypt / kurumsal SSL sertifikası kullanın (veya alternatif olarak Nginx üzerinden `wss_proxy_url` olan `wss://pbx.firma.com/asterisk/ws` ucunu deneyin).
Belirti: CORS hatası alıyorum (`Access-Control-Allow-Origin`)
Kök Neden: CRM'inizin alan adı santralin izinli CORS listesinde tanımlı değildir.
Çözüm: Santral sunucusundaki `.env` dosyasında `NORNIA_CORS_ORIGINS=https://crm.firmaniz.com` tanımını ekleyip `pm2 restart aida-backend` çalıştırın.
