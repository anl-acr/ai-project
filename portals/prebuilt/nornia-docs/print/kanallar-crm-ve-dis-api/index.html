Verify Token : ai_pbx_whatsapp_verify_token_secure  (veya Kanal Ayarlarındaki özel token)
Webhook Fields: messages

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Dış API anahtarı ile istek atınca '403 Forbidden' alıyorum
Kök Neden: Anahtarda o uç noktanın gerekli Scope yetkisi işaretli değil veya sunucu IP'si IP Whitelist listesinde yok.
Çözüm: Sistem Ayarları → Kurumsal Dış API → Canlı Erişim Günlüğü sekmesinde tam reddedilme gerekçesini okuyup Scope/IP ayarını güncelleyin.
