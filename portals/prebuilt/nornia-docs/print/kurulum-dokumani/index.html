1. Tam Çevrimdışı (Air-Gapped) Nornia ISO ile Kurulum

Yukarıdaki indirme kartından aldığınız Nornia Appliance ISO dosyası tüm işletim sistemi, Asterisk, PostgreSQL 16, Node.js 20 LTS, Python sanal ortamı ve derlenmiş Next.js arayüzünü çevrimdışı paketlenmiş halde içerir. Fiziksel sunucuya USB (Rufus / BalenaEtcher / Ventoy) ile veya VMware ESXi, Proxmox VE, Hyper-V sanallaştırma ortamlarında sanal CD/DVD olarak bağlayarak 10–15 dakika içinde sıfır dokunuşla kurulum yapabilirsiniz.

  1. 1Yukarıdaki 'Nornia ISO İndir' butonundan nornia-v3.10.11-ubuntu24.04-amd64.iso dosyasını indirin ve SHA-256 özetini doğrulayın.
  2. 2ISO dosyasını sanal makineye (VMware / Proxmox / Hyper-V) bağlayın veya fiziksel sunucu için USB belleğe yazdırıp UEFI/BIOS üzerinden ISO'dan başlatın.
  3. 3Açılış (GRUB) menüsünden 'Nornia Otomatik Kurulum' seçeneğini seçin; disk bölümleme, paket kurulumu, servis yapılandırması ve güvenlik duvarı tamamen otomatik tamamlanır.
  4. 4Sunucu yeniden başladığında TTY1 konsol ekranında görünen yerel IP adresini not edin ve tarayıcıdan http://<sunucu-ip>/setup adresini açarak 'Bölüm 02 — İlk Kurulum Sihirbazı' adımlarına geçin.
İndirilen ISO Dosyasının SHA-256 Bütünlük Doğrulaması
# macOS üzerinde doğrulama:
shasum -a 256 ~/Downloads/nornia-v3.10.11-ubuntu24.04-amd64.iso

# Linux üzerinde doğrulama:
sha256sum nornia-v3.10.11-ubuntu24.04-amd64.iso

# Beklenen SHA-256 özeti (v3.10.11):

2. Temiz Ubuntu 24.04 LTS Üzerine Script ile Çevrimiçi (Online) Kurulum

ISO bağlama imkanı olmayan bulut sunucularında (VPS, AWS, Hetzner, DigitalOcean) veya halihazırda temiz Ubuntu 24.04 LTS (amd64) kurulu makinelerde resmi çevrimiçi kurulum betiği (install_nornia_online.sh) ile tüm sistem 12 adımda otomatik kurulur. Betik; imzalı NodeSource GPG deposundan Node.js 20 LTS, PostgreSQL 16 (Port 5444 + pgvector), Asterisk PJSIP (legacy chan_sip kapalı), Python sanal ortamı, Next.js 16.4.6 üretim derlemesi, PM2 servisleri (127.0.0.1 kilitli), Nginx HTTPS/WSS + güvenlik başlıkları, UFW ve Fail2Ban (sshd + asterisk jail) katmanlarını ISO ile birebir aynı standartta kurar.

  1. 1Sunucunuza SSH ile root veya sudo yetkili kullanıcı olarak bağlanın ve işletim sisteminin Ubuntu 24.04 LTS olduğunu doğrulayın (`lsb_release -a`).
  2. 2`wget https://dokuman.nornia.com.tr/install_nornia_online.sh` komutuyla resmi kurulum betiğini sunucunuza indirin.
  3. 3Betiği `sudo bash install_nornia_online.sh` ile başlatın (parametre verilmezse etkileşimli olarak paket/erişim adresini sorar; ya da `--bundle-url` / `--asterisk-deb` bayraklarıyla tek satırda çalıştırabilirsiniz).
  4. 4Düşük bellekli sunucularda (< 6 GB RAM) betik derleme kararlılığı için otomatik 4 GB swap alanı oluşturur; kurulumda üretilen benzersiz rastgele AMI ve SSH parolaları `/root/nornia-credentials.txt` (`chmod 0600`) dosyasına kaydedilir.
  5. 5Kurulum tamamlandığında ekranda PostgreSQL, Asterisk, Backend (8000) ve Frontend (3000) sağlık doğrulaması ile `http://<sunucu-ip>/setup` adresi yazdırılır; tarayıcıdan 'Bölüm 02 — İlk Kurulum Sihirbazı' ile devam edilir.
Güvenlik & Özel Kaynak Politikası
Nornia kaynak kodları kapalı kurumsal lisans altındadır. Kurulum sonrası tüm hassas parolalar (DB, AMI, Oturum Anahtarı, SSH) sunucuya özel rastgele üretilir; backend/.env ve /root/nornia-credentials.txt dosyaları yalnızca root (chmod 0600) erişimine açıktır.
Ubuntu 24.04 LTS Script ile Çevrimiçi Kurulum Komutları
# 1. Resmi Nornia kurulum betiğini indir
wget https://dokuman.nornia.com.tr/install_nornia_online.sh

# 2. Etkileşimli başlatma
sudo bash install_nornia_online.sh

# --- VEYA tek satırda parametreli kurulum ---
sudo bash install_nornia_online.sh \
  --bundle-url "<NORNIA_KURUMSAL_PAKET_URL>" \
  --bundle-token "<YETKILI_KURULUM_ANAHTARI>" \
  --asterisk-deb "<NORNIA_ASTERISK_DEB_URL>"

# Opsiyonel güvenlik ve bulut parametreleri:
#   --sysadmin-pass '<guclu-sifre>'   : 'nornia' SSH hesabı şifresi (verilmezse rastgele üretilir)
#   --destek-pass '<destek-sifre>'    : Kısıtlı 'destek' konsol şifresi (verilmezse rastgele üretilir)
#   --lock-root-ssh                   : Root SSH girişini tamamen kapatır (PermitRootLogin no)
#   --skip-ufw                        : Mevcut harici bulut güvenlik duvarını korur

# 3. Kurulum günlüğünü canlı izleme & üretilen parolaları görme
tail -f /var/log/nornia-online-install.log
sudo cat /root/nornia-credentials.txt

3. Servis Mimarisi, Port Haritası ve Sağlık Doğrulama

Nornia tek sunucuda tümleşik kurumsal mimariyle çalışır. PM2 altında çalışan aida-app (Next.js 16.4.6 arayüz, 127.0.0.1:3000) ve aida-backend (FastAPI + AudioSocket AI TCP Motoru, 127.0.0.1:8000 / 9092), Nginx Reverse Proxy (80/443), PostgreSQL 16 (127.0.0.1:5444, ai_pbx veritabanı) ve Asterisk PJSIP (5060 UDP/TCP, 5061 TLS, 5160 Cisco TCP, 8089 WSS WebRTC, 10000–20000 UDP RTP) eşzamanlı çalışır.

Kurulum Sonrası Sunucu Sağlık Doğrulama Komutları (SSH)
# 1. PM2 servis durumunu kontrol et
pm2 status

# 2. Asterisk PJSIP transport ve kayıtlarını doğrula
asterisk -rx "pjsip show transports"
asterisk -rx "pjsip show endpoints"

# 3. Fail2Ban (sshd + asterisk) ve API sağlık kontrolü
sudo fail2ban-client status
curl -sk https://127.0.0.1/api/version

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: ISO kurulumunda sanal makine önyükleme (boot) yapmıyor
Kök Neden: VM ayarlarında Secure Boot açık kalmış veya CD/DVD önyükleme sırası diskin gerisinde.
Çözüm: VMware/Proxmox/Hyper-V ayarlarından Secure Boot'u devre dışı bırakıp ISO/CD-ROM sürücüsünü 1. önyükleme sırasına alın.
Belirti: Çevrimiçi kurulumda Next.js derlemesi bellek (OOM) hatası veriyor
Kök Neden: Sunucuda 4 GB'tan az RAM var ve swap alanı kapalı.
Çözüm: install_nornia_online.sh 6 GB altı RAM'de otomatik 4 GB swap açar; minimum 4 vCPU / 8 GB RAM önerilir.
Belirti: Kurulum bitti ama tarayıcıdan http://<ip>/setup açılmıyor
Kök Neden: Yerel güvenlik duvarı veya kurumsal ağ politikası 80/443 portunu engelliyor olabilir.
Çözüm: Sunucuda `pm2 status` ve `systemctl status nginx` çıktılarının active/online olduğunu ve `ufw status` içinde 80/443 izinlerini doğrulayın.
