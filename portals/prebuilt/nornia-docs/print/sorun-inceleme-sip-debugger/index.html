1. En Yaygın SIP Hata Kodlarını Hızlı Okuma Rehberi

Web sngrep ekranında kırmızı görünen SIP hata kodlarının anlamları:

SIP Hata Kodları Hızlı Teşhis Tablosu
401 / 407 Unauthorized   -> SIP şifresi yanlış (veya ilk challenge — 2. paket 200 OK ise normal)
403 Forbidden            -> Operatör CallerID'yi veya IP adresimizi reddetti
404 Not Found            -> Aranan DID veya dahili santralde tanımlı değil
480 / 486 Busy           -> Karşı taraf meşgul veya cihaz kayıtlı değil
488 Not Acceptable Here  -> Kodek uyuşmazlığı (Trunk'ta G.711 A-Law / alaw aktif olmalı)
503 Service Unavailable  -> Operatör hattı dolu veya erişilemiyor (Yedek Trunk devreye girer)

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Canlı yakalamayı başlattım ama hiç paket görünmüyor
Kök Neden: O esnada yeni SIP trafiği oluşmamış veya filtre kutusunda eski bir numara yazılı kalmış.
Çözüm: Arama filtresini temizleyin ve test amaçlı bir dahili veya dış arama gerçekleştirin.
