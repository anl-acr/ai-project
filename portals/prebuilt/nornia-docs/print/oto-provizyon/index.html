1. Desteklenen Markalar ve Cisco Enterprise TCP 5160

Yealink (T3x/T4x/T5x), Fanvil (X/V serisi), Grandstream (GXP/GRP), Snom, Poly ve Cisco Enterprise (78xx/79xx/88xx/89xx — TCP 5160 UseCallManager & BLF destekli) cihazlar için hazır kurumsal şablonlar bulunur. Şablonları özelleştirmek için Sistem Ayarları → Otoprovizyon Şablonları ekranını kullanabilirsiniz.

2. DHCP Option 66 ile Sıfır-Dokunuş (Zero-Touch) Kurulum

Ofis router/DHCP sunucusunda Option 66 (TFTP/HTTP Boot Server) değerini santralinizin provizyon URL'sine ayarlayarak kutudan yeni çıkan yüzlerce telefonu yalnızca ethernet kablosunu takarak kurabilirsiniz.

DHCP Option 66 / Telefon Provision URL Örneği
# Yerel Ofis (LAN) için:
http://192.168.1.25:8000/api/prov/

# Uzak Şube / Evden Çalışan (WAN - Nornia Connect) için:
https://sirketiniz.nornia.com.tr/api/prov/

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Telefon provizyon URL'sini yazdım ama ayar çekmiyor
Kök Neden: MAC adresi yanlış girilmiş veya HTTPS sertifikası eski firmware'li telefonda güvenilir görünmüyor.
Çözüm: MAC adresini harf/rakam bazında doğrulayın; eski IP telefonlarda 'Only Accept Trusted Certificates' ayarını kapatın veya LAN içinde HTTP URL kullanın.
