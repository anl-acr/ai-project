1. Üretim Santrali Güvenlik Kontrol Listesi

Santralinizi canlıya alırken şu 5 güvenlik adımını mutlaka tamamlayın:

  1. 1Ofisinizin statik dış IP'sini ve SIP Trunk operatör SBC IP'lerini Güvenlik Kalkanı → Beyaz Liste'ye ekleyin.
  2. 2Dışarıya port açmak yerine Nornia Connect (Sıfır-Port Bulut Köprüsü) kullanarak 5060/8000 portlarını internete tamamen kapatın.
  3. 3Yönetici hesaplarında Sistem Ayarları / Kullanıcı Kartı üzerinden 2FA (Google Authenticator / E-Posta / WhatsApp OTP) zorunlu yapın.
  4. 4Abone Gruplarında 'Uluslararası Arama' yetkisini yalnızca gerekli yöneticilere tanımlayın ve PIN koruması ekleyin.
  5. 5Dış API anahtarlarında mutlaka IP Beyaz Liste (Whitelist) ve sadece gerekli en dar Scope yetkilerini kullanın.

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Ofisteki tüm IP telefonlar bir anda bağlantıyı kaybetti
Kök Neden: Ofis içinde şifresi yanlış girilmiş tek bir telefon arka arkaya 401 alarak ortak ofis NAT IP'sini Fail2Ban'a düşürmüş olabilir.
Çözüm: Güvenlik Kalkanı → Engellenen IP'ler listesinden ofis IP'nizin engelini kaldırın, ofis IP'nizi Beyaz Liste'ye ekleyin ve hatalı şifreli cihazı düzeltin.
