Otel & PMS Yönetim Merkezi (Check-In/Out, AI Uyandırma, Kat Hizmetleri, ElektraWeb & FIAS)

Oteller, tatil köyleri ve hastaneler için eksiksiz Otel Santrali ve PMS (Property Management System) köprü modülüdür. Bağımsız çalışabildiği gibi ElektraWeb REST API, Oracle OPERA / Protel / Fidelio FIAS (TCP/IP) ve Open PMS API ile çift yönlü haberleşerek Check-In/Check-Out dış arama kilidi, kat hizmetleri (*71–*74), 6 dilde kişiselleştirilmiş AI uyandırma (*55), oda-arası arama kısıtlama ve çağrı ücretlendirme (Folio) süreçlerini otomatikleştirir.

Sekme 3: Ücretlendirme & Folio (Call Accounting)

Sekme 4: ElektraWeb / FIAS (OPERA & Fidelio) / Open PMS API

1. Oda Telefonu Özellik Kodları (Asterisk Dialplan)

Otel modülü aktif edildiğinde tüm oda dahilileri (IP telefon veya analog ATA gateway) aşağıdaki kısa kodları doğrudan tuşlayabilir:

Otel Oda Telefonu Kısa Kodları
*71  -> Kat Hizmetleri: Oda Temiz (Hazır)
*72  -> Kat Hizmetleri: Oda Kirli (Temizlik Bekliyor)
*73  -> Kat Hizmetleri: Oda Arıza / Teknik Bakım Gerekli
*74  -> Kat Hizmetleri: Oda Kontrol Edildi (Onaylı)
*55  -> Uyandırma Kur (Bip sesinden sonra 4 hane saat: örn. 0730)
*56  -> Aktif Oda Uyandırmasını İptal Et

2. FIAS (OPERA / Protel / Fidelio) & Open PMS REST API Örnekleri

FIAS köprüsü hem TCP Sunucu (OPERA santrale bağlanır) hem TCP İstemci (santral OPERA IFC'ye bağlanır) modunu destekler. Yerel PMS yazılımları için ise X-PMS-API-Key başlığı ile doğrudan REST entegrasyonu kullanılabilir:

Open PMS REST API & FIAS Çerçeve Yapısı
# Open PMS REST Check-In (Sedna / HMS / Mod Hotel / Özel PMS)
curl -X POST https://<alt-alan-adiniz>.nornia.com.tr/api/pms/checkin \
  -H "X-PMS-API-Key: <OPEN_API_KEY>" -H "Content-Type: application/json" \
  -d '{"room_number":"304","guest_name":"Ahmet Yilmaz","guest_language":"tr","reservation_code":"RES-9921"}'

# Open PMS REST Check-Out & Folio
curl -X POST https://<alt-alan-adiniz>.nornia.com.tr/api/pms/checkout \
  -H "X-PMS-API-Key: <OPEN_API_KEY>" -H "Content-Type: application/json" \
  -d '{"room_number":"304"}'

# FIAS TCP/IP Desteklenen Çerçeveler (STX 0x02 ... ETX 0x03)
# GI|RN304|GNAhmet Yilmaz|GLTR|G#9921|   (Check-In)
# GO|RN304|                              (Check-Out)
# RE|RN304|RS2|                          (Kat Hizmetleri: 1=Kirli, 2=Temiz, 4=Onaylı, 5=Arıza)
# WR|RN304|TI0730|                       (Uyandırma Talebi)
# PS|RN304|TA1250|PT1|                   (Folio Ücret Aktarımı - Kuruş)

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Check-In yapılan odadan dış arama yapılamıyor
Kök Neden: Check-In formunda 'Dış Arama Açık' kutusu işaretsiz bırakılmış veya santralde genel giden arama kuralı tanımlı değil.
Çözüm: Oda Panosu'ndan ilgili odanın 'Dış Arama Açık' rozetini kontrol edin; acil durum (112) ve resepsiyon aramaları her zaman serbesttir.
Belirti: FIAS bağlantısı 'Dinliyor' görünüyor ama OPERA bağlanmıyor
Kök Neden: Sunucu güvenlik duvarında (UFW) 5008/TCP portu PMS sunucusunun IP adresine açılmamış.
Çözüm: FIAS TCP portunu (varsayılan 5008/TCP) yalnızca yerel ağdaki OPERA/Protel IFC sunucusunun IP adresine izin vererek açın.
