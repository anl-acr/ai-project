Roller (RBAC), KVKK Gizlilik Onayı, Active Directory (LDAP), Lokasyon & Molalar

Kurumsal organizasyon ve uyumluluk çekirdeğidir: 60+ modül için Görüntüleme/Yazma/Silme (`:read` / `:write` / `:delete` / `:access`) granüler Rol & Yetki matrisi, 6698 sayılı KVKK metni ve değiştirilemez hukuki kullanıcı onay denetimi, Microsoft Active Directory / Azure Entra ID / OpenLDAP / FreeIPA kullanıcı eşitleme, Lokasyon-Departman ağacı ve Mola Tanımlarını içerir.

1. En Az Yetki (Least Privilege) Rol Tasarımı

Önerilen kurumsal rol hiyerarşisi: (1) Sistem Yöneticisi (Tam Yetki); (2) Çağrı Merkezi Süpervizörü (Canlı İzleme + Listen/Whisper/Barge + Kendi Kuyruk Raporları + Mola Onayı); (3) Kalite Uzmanı (Sadece Ses Kayıtları + Transkript + QA Raporları); (4) Temsilci (Yalnızca Temsilci Çağrı Paneli + Ortak Gelen Kutusu).

Sık Karşılaşılan Hatalar & Sorun Giderme

Belirti: Active Directory 'Bağlantı Testi' başarısız oluyor
Kök Neden: Bind DN formatı hatalı veya 389/636 portu firewall'da kapalı.
Çözüm: Bind DN'i 'CN=svc_pbx,OU=Services,DC=sirket,DC=local' veya 'svc_pbx@sirket.local' formatında girin; LDAPS (636) kullanıyorsanız sertifika doğrulamasını kontrol edin.
